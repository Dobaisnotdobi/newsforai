# newsforai

공식 AI 발표를 한국어 분야별 뉴스레터로 정리해 네이버 카페에 게시하는 전용 저장소.

## 확정된 운영 설정
- 게시판: https://cafe.naver.com/f-e/cafes/31813012/menus/17
- 매주 목요일 오전 11시, Asia/Seoul.
- 순서: 종합 → 영상 → 이미지 → 음악 → 기타. 중요한 신규 소식이 없는 분야는 생략.
- 최초 수집은 실행 시점 전 7일, 이후 마지막 성공한 수집 이후의 새 발표 및 중요한 후속 변경.
- 제목: [MM.DD] 이모지 1개 분야 AI 뉴스레터 — 핵심 소식. 제목은 발행일, 개별 소식은 공식 발표일.
- 각 소식: 핵심 3~5개, 이용 조건, 공식 원문 링크. 사실과 회사 전망 구분. 추측 금지.
- 동일 발표의 다중 링크를 통합하고 기존 카페 글과 게시 이력으로 중복 검사.
- 중요한 변경에는 후속 변경 표시, 이전 글 링크 및 변경 전후 내용 포함.

## 현재 상태
초기 설정 및 빈 이력만 준비됨. 수집기, 게시기, 게시판 대조 기능, 정기 실행은 아직 구현·활성화되지 않음. 실제 게시 이력 없음.

이전 자동 승인 검토에서 반복 공개 게시가 차단되었으므로, 게시 직전 확인 조건을 변경하는 명시적 확인과 인증 연결 전에는 게시를 실행하지 않는다. 사용자는 2026-11-05 즉시 게시와 주간 게시를 요청했으나 확인 조건 해소는 대기 중이다.

## 인증
네이버 연동에는 NAVER_CLIENT_ID, NAVER_CLIENT_SECRET, NAVER_REFRESH_TOKEN을 GitHub Actions Secrets에 설정해야 한다. 값은 코드, 설정, 로그, 이력에 저장하지 않는다. 기존 Aicontest 저장소의 Secrets는 자동으로 공유되지 않는다.

## 게시 이력 원칙
요청 전에 전송 중 상태를 영속 저장한다. 성공 후 글 번호, URL, 공식 출처, 게시 시각을 기록한다. 결과가 불확실하면 게시판을 확인하며 미게시가 확인되기 전 자동 재전송하지 않는다. 실패 시 수집 체크포인트를 잘못 전진시키지 않으며 미게시 큐를 유지한다.
